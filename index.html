Questions before a pilot.

What does a run actually cost us?

On Team, $0.30 a run after the first 1,000 each month. Model and tool calls are included, so there is no second bill from a model provider. Model and tool spend in our pilots has a median of $0.14 a run, and every run shows its own cost.

What happens when it gets something wrong?

Anything that changes a system, or spends more than the limit you set, waits for a sign-off, so a wrong proposal gets rejected rather than carried out. Rejections and edits feed the evals, and you can see the approval rate per workflow.

Which models does it use?

We pick the model per step, a larger one for diagnosis and smaller ones for reading and formatting. On Scale you can bring your own provider keys.

Can it act without approval?

Only for actions you mark as safe, such as posting a summary to a channel. Anything else needs a person, and you decide which person.

What happens after the pilot?

We review every run with you. If it earned its place, you move to Team and keep your workflows and run log. If not, we delete your data and you owe nothing.
